# PhonePe Transaction Analysis

## Project Overview

An interactive Power BI dashboard developed to analyze digital payment transactions and understand transaction performance across different services, service types, payment statuses, and transaction reasons.

## Business Objective

The objective of this project was to analyze transaction volume and value, identify successful and failed transactions, understand the major reasons for transaction failures, and evaluate monthly transaction trends.

## Tools & Technologies

- Power BI
- DAX
- Data Visualization
- Business Analytics

## Key Performance Indicators

- Total Users: 100.672K
- Total Transactions: 299.999K
- Total Transaction Amount: ₹3.47B
- Average Transaction Amount: ₹11.58K
- Successful Transactions: 96%
- Failed Transactions: 3.32%

## Analysis Performed

- Transaction amount by service
- Transaction amount by service type
- Payment status analysis
- Transaction failure reason analysis
- Monthly transaction trends
- User-level transaction analysis

## Dashboard Features

The dashboard provides interactive filters for payment status, service, reason, and month, allowing users to explore transaction performance from different perspectives.

## Key Insights

- Successful transactions account for the majority of the total transaction value.
- Loans contribute significantly to the overall transaction amount.
- Transaction performance can be compared across different services and service types.
- The dashboard highlights different reasons associated with unsuccessful transactions.
- Monthly analysis helps identify changes in transaction value over time.

## Project Outcome

The dashboard provides an interactive view of digital payment performance and helps identify transaction trends, service-level contribution, and areas where unsuccessful transactions can be investigated further.
